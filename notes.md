# Git and GitHub Notes

## What is Git?
Git is a version control system used to track changes in files.

## What is GitHub?
GitHub is a website where developers store and share Git projects.

## Important Git Commands

### Clone a repository
```bash
git clone <repository-url>
```

### Check status
```bash
git status
```

### Add files
```bash
git add .
```

### Commit changes
```bash
git commit -m "message"
```

### Push changes
```bash
git push origin main
